# T36 — Modo individual: rodadas no servidor

**Depende de:** T35 · **Pacotes:** server · **Branch:** `task/36-individual-rodadas-no-servidor` · **Versão:** 1.1

## Objetivo
Uma rodada por tema: cada jogador desenha todos os quadros de uma história sozinho, com tempo total; autosave e envio da história inteira; persistência dos quadros.

## Perguntas em aberto (decidir com o criador antes da T35)
- O jogador também desenha o **próprio** tema, ou só os dos outros (§9.3 diz "uma versão de cada história proposta")? Isso define o número de rodadas (N ou N − 1).
- Configurações: faixa da quantidade de quadros por história e opções de **tempo total** (§9.4).
- O editor mostra os quadros como abas, como uma página de HQ clicável ou em sequência com "próximo/anterior"?
- Apresentação (§9.5): por **tema**, mostrando todas as versões dele em seguida, ou por **jogador**, mostrando as histórias de cada um?
- Opções do modo colaborativo (miniaturas, autor desenha o último) não se aplicam aqui; confirmar.
